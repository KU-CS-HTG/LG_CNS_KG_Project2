# 예상 수령액 계산 방식으로 전환한 과정 (notes.md 이후 대화 정리)

작성일: 2026-10-27 · 관련 PR: KU-CS-HTG/LG_CNS_KG_Project2#46 (`taegyu` → `main`)

## 1. 출발점

- 직전까지의 방식: 카드의 "내 조건으로 받을 수 있는 지원"이 LLM으로 지원 유형을 정리하고, 금액은 원문에 있으면 보여 주고 없으면 웹 검색(2단계)과 공식 페이지 직접 읽기(3단계)로 찾았다.
- 문제 제기(팀장): 국민취업지원제도처럼 원문에 금액이 없는 제도는 "금액을 확인하지 못했어요"만 나온다. 2·3단계는 의미가 없다고 판단.
- 팀장이 올린 `notes.md`: Claude와 나눈 국민취업지원제도 수령액 대화. 이 대화에서 Claude가 답을 만든 방식을 프로젝트에 적용할 방법을 요청.

## 2. notes.md에서 읽어 낸 답변 방식

1. 공식 자료를 여러 개 읽고 사실마다 **출처 수준(공식/2차)**을 붙이고, 자료끼리 다른 곳은 "불일치"로 남겼다.
2. 체크리스트를 **금액 계산에 필요한 입력값**(나이, 취업경험, 가구원 수, 소득, 재산, 부양가족, 제한 사유)으로 설계했다.
3. 입력값으로 **직접 계산**하고(월 60만 원 × 6개월 = 360만 원) 경우를 나눴다(단독 가구 360만 원 / 4인 합산 0원).
4. 모르는 것은 **남은 변수**로 따로 적고 문의처(☎1350)를 안내했다.
5. 출처 링크를 공식 자료 중심으로 달았다.

## 3. 결정 사항

- 웹 검색·페이지 직접 읽기 방식은 **삭제** (정부24 페이지는 서버에서 읽기 어렵고, 한 문장으로는 "얼마"를 만들 수 없다).
- 대신 **금액 규칙을 사람이 공식 자료로 정해 파일에 저장**하고 **코드가 계산**한다 (LLM 없음, 같은 입력이면 같은 결과).
- 먼저 **국민취업지원제도 하나**로 진행한다.

## 5. 대화 중 발견·수정한 문제

1. **체크리스트와 계산기의 중복 입력**
   - 체크리스트에서 소득·재산을 체크했는데 계산기가 숫자를 다시 물었다.
   - 수정: 체크리스트 답(`check_patterns`로 조건 연결)으로 바로 계산하고, 체크로 알 수 없는 **나이대·부양가족 수만** 추가로 받는다. 숫자 입력 정밀 계산은 접어 둔 선택 칸으로 이동.
2. **Ⅱ유형이 결과에 없던 문제**
   - 금액이 자료마다 달라 일부러 뺐지만 그 이유를 화면에 보여 주지 않았다.
   - 수정: Ⅱ유형 항목을 결과에 표시.
3. **Ⅱ유형 금액 반영** (팀장이 찾은 2차 자료)
   - 취업활동비용 기본 15만 원 + 프로그램 종류·대상에 따라 3~10만 원(최대 25만 원), 참여장려수당 월 2만 원(최대 10만 원).
   - 화면에 "2차 자료 기준"을 표시하고, 정책브리핑의 다른 설명은 남은 변수에 유지.
4. **Ⅰ유형·Ⅱ유형 처리 순서**
   - 두 유형은 중복해서 받을 수 없고, Ⅰ유형 선발에서 떨어지면 Ⅱ유형으로 넘어갈 수 있다 (팀장 제공 근거: 「구직자 취업촉진 및 생활안정지원에 관한 법률」).
   - 구현: Ⅰ유형을 먼저 판정한다.

| 상황 | 화면 |
|---|---|
| Ⅰ유형 요건 충족 | Ⅰ유형 추천 + Ⅱ유형(대안) |
| Ⅰ유형 불가, 만 15~34세 | Ⅱ유형 추천 |
| Ⅰ유형 불가, 만 35~69세 | Ⅱ유형 "확인 필요" (고용센터 확인 안내) |
| 나이대 미선택 | Ⅰ유형 "확인 필요", Ⅱ유형 미표시 |

## 6. 현재 한계·확인 필요

- 규칙 값은 **초안**이다. 고용24·고용노동부·국가법령정보센터 원문과 대조하지 못했다 (작업 환경에서 접속 불가). 화면에도 "초안"으로 표시된다.
- 60만 원·부양가족 10만 원(최대 40만 원)은 대구 남구 안내문과 일치했고, 나머지는 노트 값이다.
- Ⅱ유형 금액은 2차 자료(민간 정책정보 서비스) 기준이다. 법령 링크·조항 번호는 확인하지 못했다.
- 예상 수령액 계산이 있는 제도는 **국민취업지원제도 하나뿐**이다. 다른 제도는 원문 금액이 있을 때만 보여 주고, 없으면 "금액을 확인하지 못했어요"로 안내한다.
- 청년 연령 하한이 자료마다 15세/18세로 달라 "자료 간 불일치"로 표시했다. 가구원 5인 이상은 기준중위소득이 규칙에 없어 "확인 필요"다.
- 실제 LLM·색인 경로는 가짜 객체와 AppTest로만 검증했다.
